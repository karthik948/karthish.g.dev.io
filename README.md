# Karthish G. Portfolio

This repository contains the source for my personal portfolio and resume website, published through GitHub Pages.

Website: https://karthik948.github.io/karthish.g.github.io/

## Overview

This is a single-page static resume/portfolio site for Karthish G., highlighting:

- Identity and access management experience
- DevOps and cloud engineering work
- IAM, SSO, governance, and automation projects
- Work history, skills, education, and contact information

## Project Structure

- `index.html` — page structure and content
- `styles.css` — site styling, layout, colors, and responsiveness
- `script.js` — theme toggle and optional UI interactions

## Local Preview

You can preview the site locally by serving the repository root with any static file server.

Example using Python:

```bash
cd karthish.g.github.io
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages Deployment

This project is configured for GitHub Pages.

Recommended settings in GitHub:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

After saving, GitHub will build and publish the site automatically.

## Notes

- The site is static HTML/CSS/JavaScript.
- It is designed to be lightweight, fast, and easy to maintain.
- The theme supports both light and dark modes.
