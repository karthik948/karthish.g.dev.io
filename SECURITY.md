# Security Policy

If you discover a security vulnerability in this public repository, please report it privately instead of opening a public issue.

Please email: karthish.g@gmail.com

Please include:
- a clear description of the issue
- affected URL or file path, if relevant
- steps to reproduce
- any suggested fix or mitigation

We appreciate responsible disclosure and will review reports as quickly as possible.

This site is a static public portfolio page, so please keep all reports private until a fix is available.
